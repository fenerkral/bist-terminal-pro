# BIST Terminal Pro 📊

Gerçek zamanlı Borsa İstanbul hisse analiz platformu.

## Özellikler

- 📈 Canlı BIST 100, BIST 30, BIST 50 verisi
- 🔍 Teknik Analiz Taramaları
- 💰 Hisse detay sayfaları
- ⭐ Favoriler sistemi

## Tech Stack

- Frontend: Next.js 14, TypeScript, Tailwind CSS
- Backend: FastAPI, Python
- Database: PostgreSQL

## Kurulum

```bash
cd frontend && npm install
cd backend && pip install -r requirements.txt
```
